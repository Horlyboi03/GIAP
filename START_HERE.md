## 🎯 Start Testing in 3 Simple Steps:

### 1️⃣ Clear Browser Storage (MUST DO FIRST!)
```
1. Open: http://localhost:5173
2. Press F12
3. Application tab → Local Storage → Delete "access_token"
4. Close DevTools and refresh page
```

### 2️⃣ Register & Submit Application
```
1. Go to: http://localhost:5173/register
2. Register with any email/password
3. Click "Apply Now"
4. Fill all 5 steps and submit
```

### 3️⃣ Test Admin View
```
1. Logout
2. Login as: admin@giap.org / Admin123!
3. View and manage submitted applications
```

## 🆘 Quick Troubleshooting

**Problem:** "Signature verification failed"
**Fix:** Clear local storage and login again

**Problem:** Can't submit application
**Fix:** Fill ALL required fields, especially in Step 4

**Problem:** Admin can't see applications
**Fix:** Make sure you submitted at least one application first
